# Teacher Observation Template

## Purpose

This template helps teachers record student thinking, identify mathematical misconceptions, document remediation, and monitor changes in conceptual understanding.

The focus is on understanding **how the student is thinking**, not simply whether the final answer is correct.

## Privacy Note

Do not include personally identifiable or sensitive student information in publicly shared versions of this template.

When sharing classroom examples publicly, use anonymised or fictionalised examples unless appropriate permission has been obtained.

---

## Suggested Workflow

Use this template as part of the following cycle:

**Identify → Diagnose → Explain → Remediate → Reassess → Reflect**

The aim is to understand student thinking and use that understanding to improve mathematics learning.
